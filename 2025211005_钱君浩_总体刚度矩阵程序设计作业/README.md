\# 总体刚度矩阵程序设计作业



\## 一、程序简介

本程序实现一维杆、二维桁架有限元求解，包含：

对号矩阵LM生成、单元刚度计算、总体刚度矩阵直接组装、

缩减法边界条件求解、节点位移/约束反力/单元应力后处理。



\## 二、文件结构

\- main.py        主程序，一次性运行两个算例

\- model.py       前处理、读取JSON、生成自由度与LM矩阵

\- element.py     计算一维/二维桁架单元刚度矩阵

\- assembly.py    按对号矩阵组装总体刚度矩阵

\- solver.py      缩减法处理边界条件，求解位移与约束反力

\- postprocess.py  后处理，输出位移、反力、单元应力、刚度性质

\- example1.json  一维两单元杆算例输入

\- example2.json  二维两杆桁架算例输入



\## 三、运行环境

Python 3.x + numpy



安装依赖：

pip install numpy



\## 四、运行方法

cmd / PowerShell 中执行：

python main.py



\## 五、输出内容

1\. 总体刚度矩阵

2\. 各自由度节点位移

3\. 约束自由度反力

4\. 单元长度、方向余弦、单元应力、轴力

5\. 刚度矩阵对称性、奇异性、对角元非负性校验
